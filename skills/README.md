# Email Customizer Skill for AI Agents

This repository contains an **Email Customizer Skill** (`skills/email-customizer/`) designed for AI agents to customize, generate, and execute high-converting HTML executive briefings, B2B cold emails, and multi-touch sales sequences for Nathan Scales Marketing Agency.

## 🚀 Quick Start for AI Agents

If an AI agent is git cloning or reading this repo to build or customize an email campaign:

1. **Master Skill Guide:** Read `skills/email-customizer/SKILL.md` for full instructions, workflows, and rules.
2. **Templates:** Choose from `skills/email-customizer/templates/`:
   - `executive-briefing.html`: Premium HTML executive briefing & pre-qualification audit template.
   - `b2b-outreach.html`: Clean, minimal HTML B2B outreach template.
   - `case-study-showcase.html`: HTML portfolio showcase & transformation case study template.
   - `cold-outreach-sequence.md`: Multi-touch plain text & markdown sales sequences.
3. **Reference Guides:** Refer to `skills/email-customizer/references/` for variable mappings, MSO HTML standards, and subject line frameworks.
