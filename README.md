# Nathan Scales - Portfolio & Lead Gen

A modern, high-converting landing page built for securing web development and lead generation clients. Features smooth scrolling, responsive design, and seamless Google Forms integration.

## Tech Stack
- React 19
- Vite
- Tailwind CSS v4
- Motion (Framer Motion)
- Lenis (Smooth Scrolling)

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

## Deployment

This project is optimized for deployment on Vercel. 
Simply push to GitHub and import the repository into Vercel. 
The Vercel configuration (`vercel.json`) ensures standard Single-Page App (SPA) routing is preserved.

Vercel Build Settings:
- Framework Preset: `Vite`
- Build Command: `npm run build`
- Output Directory: `dist`
